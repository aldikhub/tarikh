TARIKH — пакет веб-приложения

Содержимое:
- index.html — главная страница
- manifest.webmanifest — метаданные для установки на главный экран
- sw.js — базовое кэширование

Публикация:
1. Загрузите эти три файла на статический хостинг (например, GitHub Pages или Netlify).
2. Убедитесь, что index.html находится в корне публикуемой папки.
3. После публикации откройте выданную HTTPS-ссылку.

Важно: это ранний прототип. Кнопки разделов и тестов пока являются заглушками;
учебные тексты, реальные тесты, поиск и сохранение прогресса предстоит реализовать.
